# React + Typescript + ReactFire + React Router v7 - Práctica rutas protegidas

En esta práctica vamos a implementar una aplicación de React que utiliza TypeScript, React Router v7, ReactFire para interactuar con Firebase, y Shadcn junto con Tailwind CSS para el diseño. También utilizaremos React Hook Form para manejar formularios y Zod para la validación de datos.

## Objetivos

- Aprender a implementar rutas protegidas en una aplicación de React utilizando React Router v7.
- Entender cómo utilizar ReactFire para interactuar con Firebase.
- Aprender a utilizar Shadcn y Tailwind CSS para el diseño de la aplicación.
- Utilizar React Hook Form para manejar formularios de manera eficiente.
- Implementar validaciones con Zod para asegurar la integridad de los datos.
